{{< sectiontab title="Submittal Center" icon="4-GetInvolved.png" id="submittal-center" >}}

Momo is the forum where ideas, tools, and perspectives converge to address complex mobility challenges, and where transportation professionals from public agencies, private consulting firms, software developers, data providers, and academic and research institutions converge to shape the future of modeling mobility.

The theme for momo 2027 is **_Converge_**. For modelers, the endgame is always convergence. For all transportation professionals, momo takes up convergence in two more challenging ways: whether our data sources converge on the same story, and whether our work converges on better outcomes for the people we serve.

We welcome abstracts on any topic in transportation modeling, data, and planning, particularly those related to the **_Converge_** theme. The best submissions will not just report results; they will reflect on what made the work credible, where the evidence converged, and what the profession can learn from the approach.

Topics of particular interest include:

- **Data, methods and tools:** data management; travel surveys, big data, and data fusion; data visualization and GIS; AI and machine learning
- **Modeling:** model development in travel demand, freight, land use and socioeconomic, air quality; corridor, regional, statewide, and multi-resolution modeling; ITS and traffic microsimlation; calibration, validation, and application
- **Modes and emerging technologies:** active transportation, transit, automated and connected vehicles, freight and new commercial modes, and electric vehicles
- **Planning and policy:** equity and social justice, statewide and regional planning, sustainability and climate, performance-based planning, land use integration, travel behavior and trends, and public involvement

          color: item.color, draggable: false})
          .setLngLat(item.lnglat)
          .addTo(map)

        const popup = new maplibregl.Popup({
          closeButton: false,
          closeOnClick: false,
          focusAfterOpen: false,
          className: item.link ? 'map-label map-label-link' : 'map-label',
          anchor: 'bottom',
          offset: 24,
        })

          .setHTML(`<h3>${item.title}</h3>`)
          .addTo(map)

        if (item.link) makeClickable(popup.getElement(), item.link)
      }
    })

    // Clickable labels still need to let scroll/drag reach the map, so forward
    // those gestures to the canvas and only treat a no-drag click as a click.
    function makeClickable(el, link) {
      let dragged = false

      for (const type of ['wheel', 'mousedown', 'touchstart', 'dblclick']) {
        el.addEventListener(type, (e) => {
          if (type === 'mousedown' || type === 'touchstart') dragged = false
          map.getCanvasContainer().dispatchEvent(new e.constructor(e.type, e))
          if (type === 'wheel') e.preventDefault()
        }, {passive: false})
      }

      map.on('dragstart', () => { dragged = true })

      el.addEventListener('click', () => {
        if (!dragged) window.open(link, '_blank', 'noopener')
      })
    }
</script>
