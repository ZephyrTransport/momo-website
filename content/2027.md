<!-- OVERVIEW ######################## -->

The theme for this conference is **_converge_**. Momo is the forum where ideas, tools, and perspectives converge to address complex mobility challenges. It is also the space where transportation professionals from public agencies, private consultants and academic institutes converge to shape the future of modeling mobility. After all, as transportation modelers, our endgame is always convergence.

Get the latest updates by signing up for the [momo 2027 mailing list](https://zephyrtransport.us14.list-manage.com/subscribe?u=ceb4ce0ac1c3256b66457d9d7&id=d0c8c0c0a6).

### Propose a session

#### Do you have an idea for a session? Submit your ideas using the instructions below.

Potential Session Types

- Panel
- Workshop
- Hackathon
- User Group

We're looking for sessions that spark discussion, challenge assumptions, showcase multiple perspectives, or help attendees tackle problems together. Examples from momo 2025 include the Exploring Post-pandemic modeling panel, the General Modeling Network Specification (GMNS) workshop, and the ActivitySim user group session.

**Submission Requirements**

Description / Speakers

- Session Title: Short, clear, and descriptive (100-character maximum).
- Session Organizer(s): Name, title, affiliation, and contact email.
- Invited Speakers: Names and proposed topics of confirmed or prospective presenters.
- Session Abstract: Up to 500 words summarizing the problem, proposed approach, and relevance to practitioners.

Structure

- Session organization
- Anticipated room / material / AV requirements

Audience

- Target Audience & Technical Level: Indicate beginner, intermediate, or advanced.
- Actionable Takeaways: 2–3 concrete things attendees will learn or leave with.

#### [Download this form](/2027/momo_fullsession_template.docx) and return by email to modelingmobility@zephyrtransport.org 

Disclaimer

_Submissions may receive input from the planning committee regarding their participants and scope to ensure they align with the theme, intent, and program of the conference. The committee is committed to a collaborative process with submitters to modify sessions so they effectively address all requirements._

    ]

    map.on('load', () => {
      for (let item of points) {
        new maplibregl.Marker({
          color: item.color, draggable: false})
          .setLngLat(item.lnglat)
          .addTo(map)

        const popup = new maplibregl.Popup({
          closeButton: false,
          closeOnClick: false,
          focusAfterOpen: false,
          className: item.link ? 'map-label map-label-link' : 'map-label',
          anchor: 'bottom',
          offset: 24,
        })
          .setLngLat(item.lnglat)
          .setHTML(`<h3>${item.title}</h3>`)
          .addTo(map)

        if (item.link) makeClickable(popup.getElement(), item.link)
      }
    })

    // Clickable labels still need to let scroll/drag reach the map, so forward
    // those gestures to the canvas and only treat a no-drag click as a click.
    function makeClickable(el, link) {
      let dragged = false

      for (const type of ['wheel', 'mousedown', 'touchstart', 'dblclick']) {
        el.addEventListener(type, (e) => {
          if (type === 'mousedown' || type === 'touchstart') dragged = false
          map.getCanvasContainer().dispatchEvent(new e.constructor(e.type, e))
          if (type === 'wheel') e.preventDefault()
        }, {passive: false})
      }

      map.on('dragstart', () => { dragged = true })

      el.addEventListener('click', () => {
        if (!dragged) window.open(link, '_blank', 'noopener')
      })
    }
</script>
